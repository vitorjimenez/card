Projetos Destacados

BBB Application

→ GitHub

Java • Spring Boot • MySQL • Docker

O BBB Application é um sistema full stack inspirado no Big Brother Brasil, desenvolvido com Next.js no frontend e Spring Boot no backend, utilizando MySQL como banco de dados. O projeto é dividido em dois módulos principais: bbb-app, responsável pela interface do usuário, e sboot-user, que gerencia a API e a persistência dos dados. A aplicação permite funcionalidades como cadastro e login de usuários, gerenciamento de participantes e registro de votos, além de exibir estatísticas relacionadas à votação. O backend pode ser executado facilmente com Docker e Docker Compose, automatizando a configuração do banco de dados MySQL e da API. Já o frontend é executado separadamente via Next.js, consumindo os endpoints do backend para integração completa do sistema.
